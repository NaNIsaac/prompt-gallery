# 메이플스토리 범용 사진 프롬프트 확장 검토

2026-10-17. 사용자가 기존 인물용 프롬프트를 반려동물이나 풍경 사진만으로도 사용할 수 있게 확장하도록 요청했다. 기존 `maplestory-ingame-character`의 문구·제목·태그·사진 조건·사용법·예시 설명을 수정했다. 항목 ID와 공유 URL, `order: -19`, 승인된 인물 원본·2차 결과·썸네일은 유지한다. 기존 다른 24개 항목은 변경하지 않았으며 갤러리는 총 25개다.

## 확장 방식

- 인물은 헤어·안경·의상을 살린 SD 플레이어 캐릭터로 변환한다.
- 동물은 종·귀·털 무늬·목줄 등을 살린 펫 또는 동물 캐릭터로 변환하며 네 발 동물을 사람 몸으로 바꾸지 않는다.
- 풍경·건물은 주요 랜드마크와 좌우 배치·색을 살린 횡스크롤 게임 맵으로 변환한다. 인물·동물이 없는 사진에는 주인공·몬스터·닉네임을 추가하지 않는다.
- 사물은 얼굴·팔다리를 붙이지 않은 게임 오브젝트로 표현한다.
- 단색·스튜디오 배경에만 헤네시스를 대체 배경으로 허용한다. 실제 장소가 보이면 그 장소를 맵으로 살려 모든 사진이 동일한 버섯마을로 바뀌는 것을 피한다.
- 기존의 선명한 픽셀·2D 횡스크롤·게임 HUD 지시는 유지한다. 미니맵 지역명은 실제 장소를 추측하지 않는 '나의메이플월드'다.

## 실제 생성 테스트

내장 `image_gen.imagegen`으로 서로 다른 AI 원본 두 장을 만들고 각각 그 원본 한 장과 동일한 공개 범용 프롬프트만 전달했다. 두 원본 모두 인물이 없다. 추가 스타일 참고나 후속 편집은 사용하지 않았다. 생성 PNG는 `output/imagegen/maplestory-universal-test-2026-10-17/`에 보관한다.

강아지 원본은 거실 러그에 앉은 삼색 코기다. 결과는 큰 귀·흰 주둥이·검정과 갈색 털 무늬·짧은 다리·청록 하네스·앉은 자세를 살린 펫과 소파·러그가 있는 실내 게임 맵으로 변환됐다. 사람이 추가되지 않았다. 발판·사다리·공·방석·봉제 장난감 등 원본에 없는 게임용 소품은 추가됐다. 원본은 1448×1086, 결과는 1672×941다.

풍경 원본은 가상의 한국 산간 계곡, 왼쪽 돌 아치교와 오른쪽 전통 정자다. 결과에서 다리·정자·계곡·소나무·산의 주요 특징과 좌우 배치가 유지됐다. 사람·동물·몬스터와 머리 위 닉네임은 보이지 않는다. 사다리·다층 발판·폭포가 추가되고 가을 색감·지형·시점은 게임 맵으로 재해석됐다. 원본과 결과 모두 1672×941다.

실제 게임 리소스나 HUD를 정확히 복제한 결과는 아니다. 얼굴·복수 대상·사물 단독 입력은 이번 범용 문구로 추가 생성 테스트하지 않았다. 두 사례를 모든 사진의 성공률로 설명하지 않는다.

## 기존 공개 예시와 현재 문구

사용자가 승인한 인물 2차 결과는 그대로 유지했다. 그 이미지는 확장 전 인물용 문구로 만들어졌으므로 현재 범용 프롬프트만으로 생성한 예시라고 표시하지 않는다. 상세의 `exampleNote`에 이 차이와 강아지·풍경 추가 테스트 사실을 명시했다. 기존 원본·결과·썸네일의 SHA-256이 이전 생성 기록과 일치함을 확인했다.

## 검증

다른 24개 항목과 기존 항목의 ID·순서·예시 이미지 불변, 테스트 도구 입력과 공개 범용 문구 일치를 확인했다.

`npm run check`의 단위·데이터 검사 14개, 공유 페이지 25개 빌드, 데스크톱·모바일 Chromium 검사 10개가 모두 통과했다. 첫 실행의 브라우저 서버는 이전 테스트 실행의 포트 점유로 시작하지 못했다. 해당 프로세스가 이 저장소의 Playwright 실행임을 확인한 뒤 포트가 해제된 상태에서 전체 검증을 다시 실행했다. 새 제목 검색·상세 원문·클립보드 복사·원본과 결과 로딩·공유 URL·모바일 가로 넘침을 확인했다.
