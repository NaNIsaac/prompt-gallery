# 마네킹 v2: 원래 머리색 유지

v1에는 머리카락을 같은 아이보리색 일체형 조형으로 만들라는 명시적 지시가 있어 검정·갈색 머리까지 흰색으로 바뀌었다. 사용자의 머리색 관련 피드백에 따라 피부와 머리카락의 색 적용 범위를 구분했다. 피부는 아이보리색 레진, 머리는 원래 색과 색 분포로 도색한 조형으로 지정했다. 실제 머리카락 금지 조건도 한 올씩 사실적인 머리카락 묘사를 피하라는 뜻으로 명확히 했다.

기존 짙은 갈색 단발 원본과 새 구릿빛 갈색 곱슬머리 원본에 동일한 v2 문구만 한 번씩 적용했다. 두 시험 모두 원본 한 장 외 참고 이미지나 사진별 추가 지시·후편집은 없다. v1의 원본 생성 기록·문구·해시는 그대로 두고 [v1 결과](assets/mannequin-v1.webp)와 [썸네일](assets/mannequin-v1.thumb.webp)을 별도 보존했다. 실제 도구 입력과 새 파일 연결은 [v2 생성 기록](image-generation-2026-10-18-mannequin-v2.json)에 남겼다.

- 짙은 머리: 기존 원본의 짙은 갈색 단발·가르마·안경과 의상·난간 접촉·배경을 유지했다. 피부만 아이보리색으로 바뀌었다. 머리카락·손가락 세부와 옷 주름은 약간 달라졌다.
- 갈색 곱슬머리: 구릿빛이 섞인 갈색과 큰 곱슬 윤곽, 파란 스웨터·회색 바지·갈색 신발 및 석벽 배경을 유지했다. 얼굴·목 윤곽과 손가락 세부는 재해석됐다.

두 가상 성인 사진에서 머리가 흰색으로 통일되는 문제는 재현되지 않았다. 흰머리·금발·다색 염색·단체·다른 연령·물건을 든 손은 미검증이다. 모든 경우의 색 보존을 보장하지 않는다.

카탈로그의 기존 mannequin ID·제목·order와 다른 34개 항목을 유지했다. 대표 결과와 썸네일을 v2로 교체하고 두 머리색 예시를 연결했다. 원본·결과는 자르지 않은 1024×1536 무손실 WebP이며 원본 PNG와 디코딩 픽셀이 같음을 확인했다. 썸네일은 비율을 유지한 560×840이다.

로컬 검증: npm run check 통과. 단위·데이터 14개, 35개 상세 페이지 빌드, 데스크톱·모바일 Chromium 26개가 성공했다. 마네킹의 두 예시 전환 시 결과·원본·다운로드가 함께 바뀌고 프롬프트는 유지되는 동작까지 확인했다.
