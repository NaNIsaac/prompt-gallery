# 종이 팝업북 신규 원본 3종 등록

2026-10-18 사용자가 승인한 종이 질감 강화 v2 프롬프트와 새 원본·결과의 웹 배포를 요청했다. `paper-popup-book`을 최상단에 추가하고 인물·반려동물·풍경 예시를 선택하도록 연결했다. 프롬프트는 새 원본 테스트에 실제로 사용한 문구와 동일하다. 기존 항목의 문구·자산·순서는 유지한다.

2026-10-17 테스트에서 새로 만든 가상 성인·고양이·호숫가 사진 각각 한 장에 공개 프롬프트만 적용한 결과다. 내장 이미지 생성 도구로 각 원본과 변환을 한 번씩 생성했으며 스타일 참고·추가 지시·후속 편집은 없다. 이번 게시 과정에서 이미지를 다시 생성하지 않았다.

- 인물: 안경·노란 셔츠·남색 바지·흰 신발·앉은 자세와 파란 벤치·담·화분을 반영했다. 얼굴은 그림으로 단순화됐고 옷 주름과 벤치 일부에 입체 모형 같은 표현이 남는다.
- 반려동물: 고양이의 주황·흰 무늬·붉은 목줄·앉은 자세·꼬리를 종이로 표현했다. 눈이 둥글어졌고 화분 식물과 창밖 꽃이 달라졌다. 원본에서 잘린 화분을 전체 형태로 생성했다.
- 풍경: 왼쪽 파란 건물·붉은 지붕·부두·오른쪽 버드나무·뒤쪽 숲의 배치를 유지했다. 물은 종이 층으로 표현됐지만 반사에 사실적인 느낌이 일부 남고 책 양끝의 여백 조건은 미충족이다.

이 한계와 AI 원본·결과임을 공개 예시 설명에 표시한다. 다중 인물·동물 장면이나 실제로 접히는 공학적 구조까지 검증한 결과는 아니다. 카드·공유 미리보기는 인물 결과를 사용하고 상세에서 결과·원본·설명·확대·다운로드를 함께 전환한다.

원본과 결과는 자르지 않고 무손실 WebP로 변환해 디코딩 픽셀이 PNG와 일치하는지 확인했다. 3종 모두 1448×1086이며 기본 썸네일은 560×420이다. [실제 생성 입력과 파일 해시](image-generation-2026-10-18-paper-popup-book.json)를 보관한다.

분리된 배포 작업 트리에서 npm run check를 실행해 단위·데이터 검사 14개, 30개 상세 공유 페이지 빌드, 데스크톱·모바일 Chromium 검사 18개가 모두 통과했다. 팝업북 예시 전환 시 결과·원본·다운로드가 함께 바뀌고 프롬프트가 유지되는 동작도 검사했다. 기존 카탈로그 29개 항목의 내용과 순서가 변경되지 않았음을 비교했다.
