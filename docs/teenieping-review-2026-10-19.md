# 티니핑 v14 — 사용자 사진 한 장 원칙 반영

PR #39의 [보류 코멘트](https://github.com/Q07K/prompt-gallery/pull/39#issuecomment-6260213803)는 사용자가 본인 사진 한 장만 첨부해야 한다는 서비스 원칙을 지적했다. 사용자가 이 문제 해결을 요청해 기존 PR을 갱신한다. **현재 공개 예시와 문구는 사진 한 장만 입력한 v14**이며, 참고 3장이 필요했던 v12를 단순히 한 장용이라고 이름만 바꾼 것이 아니다.

두 호출 모두 referenced_image_paths 길이가 1이며 해당 원본 파일만 전달했다. 추가 스타일 참고, 과거 결과, 최근 대화 이미지 입력, 사진별 추가 지시나 후편집은 없었다. 실제 전달 문구는 두 호출과 공개 카탈로그에서 완전히 같다. 두 원본은 기존에 만든 AI 가상 사진이다.

안경·상의/하의 색·연속 치마와 두 다리 바지·손의 역할·앉거나 선 자세를 확인했다. 성인의 금테 안경과 파란 치마, 남자아이의 네모 안경·베이지 바지·앉은 독서를 유지했다. 꼬리는 보이지 않는다. 머리의 판타지 색 변화는 의도된 변환이다.

## 한계

v13 성인 단독 입력 시험에서는 사실적 머리/옷 질감이 강해져 그 결과를 게시하지 않고 v14에서 판타지 색과 조형 조건을 강화했다. v14도 세밀한 머리·옷·배경 질감과 흐림, 사람 귀 같은 형태, 원본과 다른 머리 모양·시선이 남는다. 남자아이의 활동 배지는 보이지 않고 두 결과는 녹색 계열 머리로 가까워졌다. 정확한 원작 스타일이나 모든 활동의 색 다양성, 실제 아이들의 만족도를 보장하지 않는다. 여자아이·다인물·동물·풍경은 v14로 시험하지 않았다.

## 이전 버전 보존

승인됐던 v12는 참고 3장+원본 한 장 방식이었다. [이전 커밋의 생성 기록](https://github.com/Q07K/prompt-gallery/blob/b4660f1af64642c0145b0b71aee92e4a6e818177/docs/image-generation-2026-10-19-teenieping.json)과 [이전 검토](https://github.com/Q07K/prompt-gallery/blob/b4660f1af64642c0145b0b71aee92e4a6e818177/docs/teenieping-review-2026-10-19.md)에 원래 입력·결과·승인 사실을 보존한다. 현재 공개 이미지와 치수는 새 v14 결과로 함께 교체했다. v12 참고 파일과 추가 첨부 지시는 현재 PR tip에서 제거했다.

## 검증

npm run check를 통과했다. 단위·데이터 검사 19개, 공유 상세 41개 빌드, 데스크톱·모바일 Chromium 30개가 성공했다. 새 1024×1536 결과의 로딩과 두 예시 전환·원본/결과 확대·다운로드, 공개 문구의 정확한 복사를 검증했다. 실제 두 호출의 이미지 입력 개수 1·추가 참고 0·공개 문구 일치, 새 결과의 PNG/WebP 디코딩 픽셀 일치, 문서 상대 링크, 기존 40개 항목 보존도 확인했다. 기존 PR #39를 갱신하며 보류 의견의 수락·병합·배포를 대신 수행하거나 완료로 주장하지 않는다.
