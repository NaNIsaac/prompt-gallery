## 원본과 선택한 결과

내장 이미지 생성 도구로 가상의 성인 한국인 남성 전신 사진을 만들었다. 갈색 가르마 머리, 둥근 검정 안경, 청재킷, 노란 상의, 크림색 바지, 빨간 운동화를 구분하기 쉬운 회색 배경의 사진이다. 실제 사용자 사진이 아니다.

같은 원본 한 장에 1차 프롬프트를 적용했다. 배경이 고해상도 도트 일러스트에 가까워, 픽셀 크기와 외곽선·명암 단계·게임 비율을 강조하는 문단을 추가한 전체 2차 프롬프트로 다시 생성했다. 2차 생성에는 1차 결과를 첨부하지 않았다. 사용자가 승인한 것은 2차 결과이며, 공개 문구는 화풍 보정 문단까지 포함한 실제 2차 입력과 동일하다.

## 수동 검토

- 헤어스타일·안경·청재킷·노란 상의·크림색 바지·빨간 운동화가 SD 도트 캐릭터에 반영됐다.
- 캐릭터 전신이 잔디 발판에 서 있고 버섯집·나무·꽃·층진 발판, 미니맵·HP·MP·경험치 막대·단축키 슬롯이 보인다.
- 2차는 1차보다 픽셀 경계와 층진 지형이 명확하고 캐릭터가 약간 옆을 향한다. 닉네임 '나의모험가'와 지역명 '헤네시스'가 읽힌다.
- 배경과 UI는 생성 모델의 재해석으로 실제 메이플스토리의 맵·게임 리소스·HUD와 다르다. 화면 전체의 픽셀 크기·명암이 완전히 균일하지 않다. 이 한계를 공개 예시 설명에도 표시했다.
- 개인 얼굴의 정확한 동일성보다 헤어·안경·복장 특징을 전달하는 예시다. 실제 게임 캐릭터나 설치 가능한 리소스를 제공하는 항목은 아니다. 다른 인물, 상반신 사진, 여러 명이 나온 사진은 추가 생성 테스트하지 않았다.

원본은 1024×1536, 결과는 1672×941, 썸네일은 560×315다. 원본은 WebP 품질 92로 변환했고 결과는 승인된 PNG와 디코딩된 픽셀이 같은 무손실 WebP로 저장했다. 썸네일만 비율을 유지해 축소했다. 자르기·색 보정·재생성은 수행하지 않았다. 실제 1차·2차 입력과 PNG·공개 WebP의 SHA-256을 생성 기록에 보관한다.

## 검증

기존 24개 항목의 내용·순서 불변, 신규 항목의 최상단 배치, 실제 2차 도구 입력과 공개 문구의 일치, 승인된 PNG와 공개 결과 WebP의 픽셀 일치를 확인했다.

`npm run check`의 단위·데이터 검사 14개, 25개 공유 페이지 빌드, 데스크톱·모바일 Chromium 검사 10개가 모두 통과했다. 첫 실행은 제한된 환경에서 브라우저 테스트 서버가 시작되지 않아 중단하고, 서버·Chromium 실행 권한으로 전체 검증을 다시 실행했다. 신규 항목의 원본·결과 로딩, 상세 원문·복사, 공유 URL, 북마크와 모바일 가로 넘침을 검사했다.
