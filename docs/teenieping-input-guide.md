# 티니핑 v12 입력 자료와 첨부 순서

이 프롬프트는 **캐릭터 참고 3장 + 변환할 인물 사진 1장**을 사용합니다. 공개 문구는 실제 승인 예시에 적용한 v12와 같습니다. 사진 한 장만으로 시험한 예시는 아닙니다.

## 참고 파일 받기

아래 파일을 열어 원본을 내려받은 뒤 다음 순서로 첨부하세요.

1. [파란 기본 캐릭터](references/teenieping/style-blue.png): 얼굴·작은 몸·매끈한 재질 참고. 꼬리나 모자는 가져오지 않습니다.
2. [자주색 기본 캐릭터](references/teenieping/style-magenta.png): 짧은 팔다리·머리 덩어리 참고.
3. [빨간 의상 캐릭터](references/teenieping/style-red.png): 작은 몸 위에 놓이는 의상 참고. 모든 사진에 치마나 분홍색을 적용하는 지시는 아닙니다.
4. 변환하려는 인물 사진 한 장.

[공개 v12 문구](teenieping-prompt-v12.txt)를 복사해 네 이미지와 함께 보내세요. 사용자 제공 참고 파일을 생성 시험에 사용한 그대로 보관했으며 외부 원본 URL은 제공되지 않았습니다. 참고 파일을 바꾸면 이번 예시와 입력 조건이 달라집니다.

## 변환 방식

머리 모양·안경·상의/하의 종류와 주요 색·행동을 티니핑의 작은 몸으로 옮깁니다. 머리색은 원래 갈색·검정에 고정하지 않고 활동을 상징하는 판타지 색으로 바뀝니다. 옷 색과 치마/바지 구분은 원본을 유지하도록 지시합니다. 모든 인물을 같은 분홍색 공주형 캐릭터로 만들지 않습니다.
