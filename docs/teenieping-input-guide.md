# 내 사진을 나만의 티니핑으로 — 사진 한 장 사용법

1. 머리 모양·안경·옷과 행동이 잘 보이는 **인물 사진 한 장**을 첨부하세요.
2. [공개 v14 프롬프트](teenieping-prompt-v14.txt)를 복사해 사진과 함께 보내세요.

추가 캐릭터 참고 이미지, 파일 다운로드, 별도 첨부 순서는 필요하지 않습니다.

## 변환 방식

사진 속 머리 실루엣·안경·옷의 종류와 주요 색·행동을 작은 티니핑 캐릭터로 옮깁니다. 머리·눈·몸 색은 활동을 상징하는 판타지 색으로 바뀝니다. 옷·안경·소품의 원래 색과 치마/바지 구분은 유지하도록 지시합니다.

## 실제 한 장 입력 예시

- [가상 성인 사진](../assets/images/teenieping.reference.webp) → [식물 돌봄 v14 결과](../assets/images/teenieping.webp)
- [가상 남자아이 사진](../assets/images/teenieping.boy.reference.webp) → [독서 v14 결과](../assets/images/teenieping.boy.webp)

각 예시는 해당 사진 한 장과 같은 공개 문구만 사용했습니다. 원본과 결과는 AI 생성이며 실제 사용자·어린이 사진이 아닙니다.

세밀한 머리·옷 질감과 사람 귀 같은 형태, 원본과 다른 머리 모양·시선이 남습니다. 두 예시의 머리색은 녹색 계열로 가까우며 모든 활동에서 서로 다른 색을 보장하지 않습니다. 원작과 완전히 같거나 실제 아이들의 만족도를 확인했다고 주장하지 않습니다. 여자아이·다인물·동물·풍경은 v14로 시험하지 않았습니다.
