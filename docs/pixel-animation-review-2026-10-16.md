# 손그림 애니메이션·픽셀 OOTD 등록 검토

같은 원본으로 비교한 8종 중 사용자가 선택한 8번 손그림 애니메이션과 7번 픽셀 OOTD를 등록한다. 공개 예시는 각각 서로 다른 새 AI 원본으로 만들었으며, 비교 테스트의 여성·고양이 공통 원본을 재사용하지 않았다.

## 생성 및 등록 방식

- 내장 `image_gen.imagegen`으로 각 원본을 새로 만들고, 해당 원본 한 장과 최종 공개 한국어 프롬프트만으로 변환했다. 다른 스타일 지시나 후속 보정, 재시도는 없었다.
- 비교용 특정 의상·인물 지시를 재사용 가능한 문구로 바꾸었다. 손그림은 원본의 피사체와 장면 전체를 유지하고, 픽셀은 지정한 인물 한 명의 착장을 반영한다.
- 원본·결과는 자르지 않고 WebP로 변환했고, 썸네일만 비율을 유지해 폭 560px로 축소했다. 픽셀 결과의 알파 채널을 유지했다.
- 요청 순서에 따라 손그림 `order: -12`, 픽셀 `order: -11`로 추가했다. 기존 16개 항목의 내용과 상대 순서는 유지했다.

## 손그림 애니메이션

- 원본: 긴 머리의 성인 여성, 파란 원피스, 빨간 책, 밀짚 가방, 해안가 책방과 민트색 문이 있는 가상 여행 사진.
- 결과: 인물 한 명과 의상, 책, 책방·해안의 주요 배치를 유지했다. 선화와 수채화 질감, 따뜻한 햇빛이 적용됐다.
- 한계: 얼굴과 꽃·책 등 작은 디테일은 일러스트로 재해석된다. 특정 스튜디오 화풍을 보장하는 예시가 아니다.
- 공개 자산: `assets/images/warm-handdrawn-animation.reference.webp`, `warm-handdrawn-animation.webp`, `warm-handdrawn-animation.thumb.webp`.

## 픽셀 OOTD

- 원본: 짧은 검은 머리의 성인 남성, 청록색 재킷, 회색 티셔츠, 검은 바지, 주황 가방, 빨간 운동화가 보이는 강변 전신 사진.
- 결과: 전신 실루엣, 헤어스타일과 착장·소품 색을 알아볼 수 있게 반영했다. 바닥과 강변 배경은 제거됐다.
- 파일 검토: WebP 결과의 `hasAlpha: true`와 알파 채널 최솟값 0을 확인했다. 원본·결과는 1024×1536, 썸네일은 560×840이다.
- 한계: 가장자리의 부드러운 반투명 색 번짐은 프롬프트의 빛 번짐 금지 조건을 완전히 만족하지 못했다. 엄격한 제한 팔레트 게임 스프라이트가 아닌 픽셀풍 아바타이며, 이를 `exampleNote`에 표시했다.
- 공개 자산: `assets/images/pixel-ootd.reference.webp`, `pixel-ootd.webp`, `pixel-ootd.thumb.webp`.

원본 생성 프롬프트, 실제 도구 입력, 반환된 원본 PNG와 공개 파일의 SHA-256 및 크기는 [생성 기록](image-generation-2026-10-16-pixel-animation.json)에 보관한다. 두 원본은 서로 다른 파일이며 기존 카탈로그의 원본과도 중복되지 않는지 기존 데이터 검사로 검증한다.
