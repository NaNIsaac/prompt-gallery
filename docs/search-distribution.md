# 검색 유입 콘텐츠와 소개글 초안

## 이번 변경

홈페이지가 GPT 사진 변환 프롬프트 모음임을 제목·헤딩·설명에 명시한다. `src/search-guides.mjs`에서 대표 5개 페이지의 검색 제목·설명과 사진 준비·시험 결과·한계를 관리한다. 정적 본문과 상세 모달이 같은 자료를 사용하고 JavaScript가 검색 제목을 원래 제목으로 덮어쓰지 않게 한다. 원래 카드 제목·프롬프트 원문·URL·이미지는 유지한다.

대표 항목은 카톡 이모티콘, 티니핑풍 캐릭터, 그림판 낙서, 아이돌 화보, 여행 도자기 무드등이다. 검색량 또는 인기도 순위로 선정한 항목은 아니다. GPT는 검색용 작업 표현으로 사용하며 실제 사용 도구는 본문에 ChatGPT로 명시한다. 노출 이후 Search Console 검색어·노출·클릭으로 표현을 조정한다.

## 직접 운영하는 블로그용 초안

제목: GPT로 내 사진을 카톡 이모티콘 9종으로 만들기 — 원본과 결과 비교

내 사진 한 장으로 인사·웃음·감사 등 9가지 감정의 캐릭터 시안을 만드는 ChatGPT 프롬프트를 정리했습니다.

얼굴·머리·안경·옷이 잘 보이는 한 사람의 사진을 준비하고, 사진과 프롬프트를 ChatGPT에 함께 보내면 됩니다. 공개 예시는 AI 가상 성인 사진 한 장으로 시험했으며, 안경과 의상 색을 살린 3×3 감정 시트를 확인할 수 있습니다.

결과는 한 장의 이모티콘 스타일 시안입니다. 카카오 제출 규격에 맞춘 9개 개별 파일 패키지는 아니며, 투명 여백의 잔점과 경계는 추가 정리가 필요할 수 있습니다.

원본·결과 이미지와 전체 프롬프트: https://q07k-prompt-gallery.pages.dev/prompts/kakao-emoticons/

게시할 때는 위 페이지의 공개 원본·결과를 짝지어 보여주고 'AI 가상 사진·AI 생성 결과' 표시를 유지한다. 이미지 생성 완료나 카카오 등록 승인을 보장하는 표현은 사용하지 않는다.

## 직접 운영하는 SNS용 짧은 초안

사진 한 장으로 카톡 이모티콘 느낌의 감정 9종을 만들어봤어요. ChatGPT에 넣을 문구와 원본·결과 비교를 함께 정리했습니다. AI 가상 성인으로 시험한 시안이며 카카오 등록용 개별 파일은 별도 준비가 필요해요.

## 다른 대표 페이지를 소개할 때

- 티니핑풍 캐릭터: https://q07k-prompt-gallery.pages.dev/prompts/teenieping/ — 원작 조형과 차이가 남는다는 점을 함께 설명한다.
- 그림판 낙서: https://q07k-prompt-gallery.pages.dev/prompts/eyes-closed-mspaint/ — 사진 특징을 줄이는 이미지 생성이며 실제 그림판 조작이 아님을 밝힌다.
- 아이돌 화보: https://q07k-prompt-gallery.pages.dev/prompts/kpop-idol/ — 공개 문구의 성인·27세·단발 기준과 안경 제거 조건을 알린다.
- 여행 무드등: https://q07k-prompt-gallery.pages.dev/prompts/travel-ceramic-nightlight/ — 실물 제품이 아닌 AI 이미지임을 밝힌다.

이 문서는 검토용 초안이며 블로그·SNS·톡방에 자동 게시하지 않는다. 공개할 서비스·계정과 게시 요청이 지정되면 해당 범위에서 진행한다.

## 운영 확인

- 사이트맵의 주소 수와 기존 URL을 유지하고 Search Console 인증 태그를 보존한다.
- 검색 유입은 Search Console 검색어·노출·클릭, 방문 이후 행동은 GA4 전체 `prompt_copy`와 `surface=card/detail`로 확인한다.
- 복사 수를 실제 이미지 생성 완료나 결과 만족도로 해석하지 않는다.
- 현재 URL query를 제거하는 분석 설정이 있으므로 UTM 캠페인 귀속을 검증하지 않은 상태에서 캠페인별 성과를 보장하지 않는다.
- 네이버 등록은 https://searchadvisor.naver.com/ 에서 같은 사이트 URL을 등록·인증한 뒤 사이트맵을 제출한다. Google 소유권 인증과 별개의 서비스다.
