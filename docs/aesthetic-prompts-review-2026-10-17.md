# 숲 이중노출·풍경 목판화 2종 등록 검토

후속 수정: 숲 이중노출은 사용자 요청으로 얼굴의 수채화·색연필 표현을 강화한 새 결과로 교체했다. 현재 문구와 예시는 [그림체 수정 검토](forest-illustration-review-2026-10-17.md)와 [새 생성 기록](image-generation-2026-10-17-forest-illustration.json)을 따른다. 아래는 최초 등록 당시의 기록이다.

2026-10-17. 사용자가 조사 후보 중 2번과 8번을 선택해 신규 두 항목을 추가했다. 기존 20개 항목의 내용과 상대 순서는 유지하고, 요청 순서대로 `forest-double-exposure`(-16), `ukiyo-e-landscape`(-15)를 상단에 둔다. 총 공개 항목은 22개다.

각 항목마다 다른 AI 원본을 새로 만들고, 그 한 장과 최종 공개 프롬프트만 내장 `image_gen` 도구에 전달했다. 외부 스타일 예시는 도구에 첨부하지 않았고 변환 재시도나 후속 편집은 없었다. 전체 이미지를 자르거나 보정하지 않고 WebP로 변환하고, 썸네일만 비율을 유지해 축소했다.

## 정면 사진으로 만드는 숲 이중노출

[원본](../assets/images/forest-double-exposure.reference.webp) · [결과](../assets/images/forest-double-exposure.webp)

최초에는 측면 인물 원본을 만들었지만, 사용자가 정면 사진을 입력하는 흐름을 요청했다. 측면 원본은 공개 예시와 변환 테스트에서 제외하고 정면을 바라보는 가상의 성인 여성 사진을 새로 만들었다. 측면 원본으로 만든 변환 결과는 없다.

최종 공개 프롬프트와 첨부 안내는 정면 사진을 사용하며, 측면 사진을 별도로 요구하지 않는다. 정면 얼굴의 특징을 바탕으로 결과에서 옆모습을 재해석한다. 이는 보이지 않는 옆얼굴을 정확하게 복원한다는 뜻이 아니다.

결과에는 짧은 갈색 단발·작은 금색 귀걸이와 원본의 얼굴 인상이 반영됐다. 머리·목·어깨 안에 푸른 산과 숲·옅은 안개·따뜻한 새벽빛이 겹쳐지고, 바깥의 가지와 잎은 흰 여백으로 흩어진다. 글자·로고·워터마크는 보이지 않는다. 얼굴의 피부와 눈에는 사실적인 질감이 남아 있어, 얼굴까지 모두 같은 일러스트로 표현하라는 조건은 완전히 충족하지 않았다. 이 제한과 옆얼굴의 생성 사실을 카드의 `exampleNote`에 표시한다.

결과와 원본은 모두 1024×1536이며, 썸네일은 560×840이다. 하나의 정면 사진에서 확인한 결과로, 모든 얼굴의 닮음이나 변환 성공률을 뜻하지 않는다.

## 해안 마을의 풍경 목판화

[원본](../assets/images/ukiyo-e-landscape.reference.webp) · [결과](../assets/images/ukiyo-e-landscape.webp)

원본은 한국 동해안 분위기로 만든 가상의 해안 마을 사진이다. 실제 여행지를 촬영한 사진이 아니다. 왼쪽의 낮은 집들과 돌담·소나무 능선, 가운데의 물길과 오른쪽의 흰 등대를 비교했다.

주요 구도와 가로 비율을 유지하면서 쪽빛·흙빛·이끼색의 평평한 색면, 짙은 윤곽과 종이 결이 표현됐다. 지붕·바위·물결과 구름은 판화식 형태로 단순화됐고, 등대 꼭대기의 붉은색은 약해졌다. 새로운 탑·산·사람·배나 글자·인장을 추가하지 않았다. 수면의 잔물결은 구체적인 조각 모양과 위치까지 그대로 보존된 것이 아니다.

결과와 원본은 모두 1536×1024이며, 썸네일은 560×373이다. 사람이 함께 있는 사진의 보존 조건은 공개 문구에 포함했지만 별도 생성 테스트는 진행하지 않았다. 특정 시대 목판화의 역사적 복원이나 실제 목판 제작용 도안으로 설명하지 않는다.

## 기록과 출처

[실제 입력·원본 생성 문구·아티팩트와 공개 파일의 SHA-256](image-generation-2026-10-17-aesthetic.json)에 두 항목과 제외한 측면 원본을 기록했다. 최종 공개 문구와 변환 도구에 보낸 `toolPrompt`는 동일하다.

스타일 참고 자료는 [이중노출](https://aistyleatlas.com/en/styles/double-exposure)과 [목판화](https://www.myaiart.io/features/ai-ukiyo-e-style-generator/)이며, [선택 전 조사와 한국어 초안](prompt-research-aesthetic-2026-10-17.md)을 별도로 남긴다. 한국어 공개 문구는 이 프로젝트에서 작성했다.

## 로컬 검증

`npm run check`의 단위·데이터 검사 14개와 22개 공유 페이지 빌드가 통과했다. 제한된 실행 환경에서 브라우저 서버가 진행되지 않아 첫 실행을 중단하고, 서버와 Chromium 실행 권한으로 `npm run test:e2e`를 다시 실행해 데스크톱·모바일 10개 검사를 모두 통과했다. 기존 20개 카탈로그 항목의 불변, 공개 프롬프트와 실제 입력의 일치, 여섯 자산의 SHA-256도 확인했다.
