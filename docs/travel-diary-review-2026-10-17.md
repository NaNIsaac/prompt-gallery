## 승인한 원본과 변환

최초에는 맑은 해안 마을과 카페 테이블을 담은 AI 원본으로 테스트했다. 사용자가 실제 사람들이 찍을 법한 느낌이 아니라고 평가해 해당 원본과 결과는 공개하지 않는다. 흐린 날 항구 카페에서 동행이 휴대폰으로 찍은 듯한 새 AI 원본을 만들었다. 회색 후드집업, 턱을 괸 자세, 창문 반사와 주차된 차, 마시던 커피와 먹던 빵을 담았다. 사람과 장소 모두 가상이며 실제 여행 사진이 아니다.

새 원본 한 장과 최초 변환 때와 같은 한국어 프롬프트만 내장 이미지 생성 도구에 전달했다. 스타일 참고나 후속 편집은 없었다. 공개 문구는 실제 변환 입력과 동일하다.

## 수동 검토

- 인물의 얼굴 인상·머리·옷차림·자세와 창밖 항구·차·테이블·컵의 주요 특징이 유지됐다.
- 큰 사진 한 장과 항구·커피를 보여주는 작은 사진 두 장, 미색의 펼친 다이어리, 찢은 종이와 마스킹테이프, 압화, 빈 메모 공간이 표현됐다. 결과에 읽을 수 있는 글자·로고·워터마크는 보이지 않는다.
- 작은 사진과 인물·소품의 세부는 생성 과정에서 재해석됐다. 원본 픽셀을 정확히 잘라 붙이는 기능으로 설명하지 않는다.
- 원본에 식물이 없는데 장식용 압화가 추가돼 원본 식물에 대응하는 조건은 엄밀히 충족하지 않았다. 카드의 예시 설명에 이를 표시한다.
- 사진이 없는 경우, 여러 인물, 풍경만 있는 사진, 음식만 있는 사진은 별도로 생성 테스트하지 않았다. 예시 한 장의 결과를 범용 성공률로 설명하지 않는다.

공개 원본과 결과는 1448×1086, 썸네일은 560×420이다. 전체 화면을 자르거나 보정하지 않고 WebP로 변환했다. 초기 예시와 최종 원본·결과의 실제 입력 및 해시를 생성 기록에 함께 보관한다.

## 검증

`npm run check`의 단위·데이터 검사 14개, 23개 공유 페이지 빌드, 데스크톱·모바일 Chromium 검사 10개가 모두 통과했다. 첫 시도는 제한된 실행 환경에서 테스트 서버가 멈춰 종료하고 서버·Chromium 실행 권한으로 전체 검증을 다시 실행했다. 기존 22개 항목의 내용·순서 불변, 새 항목의 최상단 배치, 공개 문구와 실제 변환 입력의 일치, 공개 자산 세 파일의 SHA-256을 확인했다.
