# 개구리 왕눈이 주인공 등록 검토

2026-10-18 사용자가 테스트 결과를 웹에 배포하도록 요청했다. 가상 성인 사진과 내장 이미지 생성 도구로 만든 2차 결과를 등록한다.

## 공개 프롬프트와 예시

공개 문구는 transform-v2.prompt.txt의 실제 2차 입력과 문자 단위로 일치한다. 해당 원본 사진 한 장만 첨부했으며 별도의 스타일 이미지나 추가 지시를 넣지 않았다. 실제 입력, 두 차례 시도, 파일 크기와 SHA-256은 [생성 기록](image-generation-2026-10-18-demetan.json)에 보관한다.

## 육안 검토

가상 원본의 갈색 머리·둥근 안경·겨자색 겉옷·갈색 가방이 중앙의 새로운 개구리 주인공으로 이어진다. 1차에서 빠졌던 왕눈이의 붉은 머리와 파란 멜빵바지, 아로미의 꽃과 붉은 치마가 2차에 표현됐다. 중앙 인물은 입과 피리가 연결된 연주 자세이고, 세 캐릭터와 연꽃·연잎·갈대가 있는 가로 4:3 장면이다. 실사 얼굴 합성·분할·문자·워터마크는 보이지 않는다.

원작 방송 프레임보다 둥글고 귀여운 그림책풍이며 조연의 얼굴 비례도 다르다. 머리카락이 작은 앞머리보다 크게 남았고 안경테 일부, 작은 점, 바지 색, 물갈퀴가 생략됐다. 이 한계를 상세의 예시 설명에 공개한다.

## 자산과 등록 순서

원본과 결과는 픽셀이 동일한 lossless WebP로 변환했다. 썸네일만 비율을 유지해 가로 640픽셀로 축소했다. 새 항목의 order는 기존 최솟값보다 1 작게 지정하고 이전 항목과 상대 순서를 유지한다.

검증은 npm run check로 데이터·빌드·데스크톱/모바일 브라우저 동작을 확인한다. CI 및 공개 배포 결과는 해당 PR과 Actions 실행에서 확인한다.
