# 소닉 주인공 등록 검토

2026-10-18 사용자가 두 사진 테스트를 확인한 뒤 웹 배포를 요청했다. 최신 main을 기준으로 소닉 항목 한 개와 예시 두 쌍을 추가한다.

- 가상 성인 여성·남성 사진을 각각 새로 생성했고 두 사진에 동일한 변환 프롬프트를 적용했다. 공개 문구는 실제 두 테스트의 입력과 같다.
- 가장 최근 확인한 땋은 머리 예시를 기본 카드와 공유 이미지로 사용한다. 상세에서 안경 예시로 바꾸면 원본·결과·설명이 함께 전환된다.
- 원본과 결과는 자르지 않고 lossless WebP로 변환했으며 디코딩한 픽셀의 일치와 SHA-256을 기록했다. 썸네일만 비율을 유지해 축소했다.
- 새 주인공의 옷 색·소품·헤어 특징과 소닉·테일즈의 질주 구도를 눈으로 비교했다. 원작보다 세밀한 질감, 머리 위 여백 부족, 주근깨 미보존 및 작은 문양 생성 등의 한계를 각 예시에 표시했다.
- 기존 항목과 정렬 값은 유지하고 새 항목만 최상단에 추가했다. 사이트에서 쓰지 않는 테스트 PNG는 공개 자산 폴더에 넣지 않았다.
- 실제 입력과 파일 해시는 [생성 기록](image-generation-2026-10-18-sonic.json)에 보관한다. 배포 전 npm run check와 데스크톱·모바일 예시 전환을 확인한다.
