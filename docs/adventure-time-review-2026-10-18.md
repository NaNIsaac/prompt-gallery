# 어드벤처 타임 주인공 등록 검토

2026-10-18 사용자가 한국인 가상 인물의 원본과 결과를 확인한 뒤 웹 배포를 요청했다. 이 원본·결과 한 쌍을 새 항목으로 최상단에 추가했다. 기존 항목의 문구·이미지·상대 순서는 유지했다.

내장 image_gen.imagegen으로 한국인 성인 여성으로 설정한 사진을 새로 생성하고, 이전 두 인물 테스트의 최종 변환 프롬프트 전체와 이 사진 한 장만 입력했다. 추가 그림체 참고나 이전 결과는 입력하지 않았다. 검은 땋은 머리, 안경 없음, 노란 상의, 보라색 치마, 초록 가방, 흰 운동화가 유지되고 핀·제이크와 함께 모험하는 인물이 되었다. 얼굴까지 단순한 점눈과 선으로 다시 그렸다.

공개 프롬프트에서는 첫 원본에만 맞춘 “재킷은 주황색의 단순한 한 덩어리로”를 “옷은 사진 속 종류와 대표 색을 유지한 단순한 덩어리로”로 정리했다. 이번 예시는 수정 전 프롬프트로 생성되었고 새 문구로 재생성하지 않았다. 실제 예시에서는 노란 상의를 유지했다. 공개 예시 설명과 생성 기록에 이 차이를 표시하고 실제 도구 입력 전체를 보존했다.

배경·의상에 옅은 명암과 세부 묘사가 남아 초기 방송 프레임과 완전히 같은 단순화라고 보기는 어렵다. 배경 얼음산에 요청하지 않은 얼굴 모양이 있고, 제이크는 팔을 늘렸지만 걸어서 건너는 명확한 다리 구조는 아니다. 이 한계를 공개 설명에 기록했다. 개인 얼굴 비례는 만화 표현에 맞춰 크게 단순해진다.
