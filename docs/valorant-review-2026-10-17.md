## 생성 과정과 공개 문구

가상의 성인 한국인 상반신 사진을 내장 이미지 생성 도구로 만들었다. 원본 한 장으로 1차 요원 장면을 만든 뒤, 원본과 1차 결과 두 장을 참조해 피부·머리카락·전술 장비·배경의 면과 재질을 단순화했다. 사용자가 선택한 것은 이 2차 편집 결과다.

공개 문구는 원본 사진 한 장만 첨부해 사용할 수 있도록 두 단계의 지시를 합친 한국어 통합본이다. 이 통합본만 적용해 만든 결과로 표시하지 않고, 두 단계 편집과 문구 차이를 상세의 exampleNote와 사용 안내에 명시했다. 실제 1차·2차 입력은 생성 기록에 그대로 보관한다.

## 육안 검토

- 검은 가르마 머리와 얼굴 인상, 남색·청록색 전술복, 낮춰 든 소총이 보인다.
- 2차는 1차보다 피부·헤어·장비·배경의 표면이 단순해졌고 각진 면과 색면이 두드러진다.
- 미니맵, 7 대 5 점수, 1:24 타이머, 체력 100, 탄약 25 / 75와 능력 아이콘을 표현했다.
- 얼굴 비율은 스타일 변환으로 달라졌으며 맵·총기·HUD는 생성 모델의 재해석이다. 실제 게임 캡처나 정확한 UI 재현이 아니다.
- 공개 통합 문구, 다른 사람·여러 명의 사진은 추가 이미지 생성 테스트하지 않았다.

원본과 결과는 무손실 WebP로 변환했고 디코딩된 픽셀이 선택한 PNG와 동일함을 확인했다. 결과 크기는 1672×941이며 썸네일만 폭 560으로 비율을 유지해 축소했다. 자르기·색 보정·재생성은 하지 않았다.

## 검증

단위·데이터 검사 14개, 26개 공유 페이지 빌드, 데스크톱·모바일 Chromium 브라우저 검사 10개를 통과했다. `npm run check`의 브라우저 단계에서 기본 4180번 포트가 다른 작업에 사용 중이어서 시작하지 못했고, 동일 설정을 임시 파일에서 4187번 포트로만 바꿔 브라우저 검사 전체를 통과했다. 배포용 설정은 변경하지 않았다. 원본·결과 이미지 로딩, 프롬프트의 정확한 복사, 공유 링크, 검색·필터, 북마크, 모바일 가로 넘침을 검사했다.
