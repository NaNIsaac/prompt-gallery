# 마인크래프트 범용 프롬프트 인물·반려동물·풍경 예시 등록

2026-10-17. 사용자가 범용 프롬프트로 기존 인물 사진까지 다시 시험한 뒤 웹 배포를 요청했다. `minecraft-ingame-character`의 기본 결과를 새 세로 인물 이미지로 교체하고, 같은 공개 문구로 시험한 코기·해안 풍경을 선택 가능한 예시로 연결했다. ID·프롬프트·순서와 다른 카탈로그 항목은 그대로다.

세 예시는 모두 내장 이미지 생성 도구에 원본 한 장과 현재 범용 프롬프트만 전달해 각각 1회 생성했다. 추가 스타일 참고·후속 편집은 없다. 인물 원본은 최초 테스트의 노란 재킷 가상 성인 사진을 그대로 사용했고, 반려동물·풍경은 별도로 만든 가상의 코기·해안 마을 사진이다. 이번 게시 과정에서 이미지를 다시 생성하지 않았다.

인물은 헤어·안경·옷차림과 공원길의 맥락, 세로 화면 비율을 유지했으며 원본에 없던 곡괭이는 없다. 자세·길·나무 배치·등불 형태와 캐릭터 비율은 재해석됐다. 코기는 귀·털 무늬·청록색 목줄·네 발 구조를 유지했지만 다리가 길어졌고 흐린 날씨가 맑아졌다. 풍경은 집 세 채·돌담·언덕·길·바다의 주요 배치를 유지했지만 회색 하늘·바다는 맑고 파란 색조로 바뀌었다. 반려동물·풍경에 사람이나 플레이어 손·무기를 추가하지 않았다. 각 예시 설명에 이러한 차이를 표시한다.

상세의 인물·반려동물·풍경 선택은 결과 이미지·입력 원본·검토 설명·이미지 확대 및 다운로드 대상을 함께 바꾼다. 프롬프트와 공유 URL은 하나다. 기본 카드·썸네일·공유 이미지는 새 인물 결과를 사용한다. 단일 예시 항목에는 선택 버튼을 표시하지 않는다. 동일한 공통 예시 선택 기능을 준비 중인 작업 폴더에서 필요한 UI·검증 부분만 재사용했고, 별도로 진행 중인 메이플스토리 카탈로그·이미지 변경은 포함하지 않았다.

인물 결과는 1024×1536, 코기는 1448×1086, 풍경은 1536×1024다. 결과 WebP는 무손실로 변환해 원본 PNG와 디코딩한 픽셀의 일치를 검사했다. 기존 인물 레퍼런스는 그대로 두고 반려동물·풍경 레퍼런스만 WebP로 변환했다. 썸네일은 인물 결과를 비율대로 560×840으로 축소했다. 최초 인물용 생성 기록과 범용 문구 수정 기록은 과거 사실 그대로 보존한다.

분리된 작업 트리에서 `npm run check`의 단위·데이터 검사 14개, 28개 공유 페이지 빌드, 데스크톱·모바일 Chromium 검사 12개가 모두 통과했다. 추가 검사는 예시별 결과·원본·설명·확대·다운로드 연결, 공통 프롬프트 유지와 복사, 새로고침 시 기본 예시 선택, 단일 예시 화면에서 선택 버튼 숨김을 확인했다.
