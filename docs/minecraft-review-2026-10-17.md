## 같은 날 범용 사진용으로 확장

후속 요청에 따라 제목을 ‘내 사진을 마인크래프트 세상으로’로 바꾸고 인물·반려동물·풍경·건물·음식·사물 사진용으로 공개 문구와 첨부 안내를 확장했다. [수정 전후 문구와 자산 해시](minecraft-prompt-revision-2026-10-17.json)를 별도로 보관한다. 기존 ID와 상세 URL, 카테고리, 순서, 원본·결과·썸네일은 유지한다.

인물이 있으면 플레이어 스킨, 동물이 있으면 종·무늬·귀·꼬리·다리 수를 살린 블록 동물, 풍경·건물이면 지형과 건축물 배치를 살린 블록 월드로 변환한다. 사람이 없는 사진에도 인물을 요구하지 않으며 플레이어를 추가하지 않는다. 사람·동물을 복수로 포함한 장면은 주요 대상을 함께 처리한다. 원본 구도·비율·시간대·날씨를 유지하고, 과거의 고정된 낮의 잔디 평원·16:9·철 곡괭이 조건은 제거했다. 배경이 거의 없는 단독 피사체 사진에만 최소한의 게임 배경을 허용한다.

현재 범용 문구로 이미지를 다시 생성하지 않았다. 기존 인물 예시는 과거 문구로 만든 것이므로 현재 문구의 성공 예시로 표시하지 않는다. 특히 예시에 남아 있는 철 곡괭이는 당시 문구의 지시이고 현재 문구는 원본에 없는 도구를 추가하지 않도록 한다. 반려동물·풍경·사물의 이미지 생성 테스트도 아직 수행하지 않았으며 공개 예시 설명에 이 점을 표시했다. 최초 생성 기록은 당시 사실 그대로 유지한다.

범용 문구 수정 후에도 `npm run check`의 단위·데이터 검사 14개, 25개 공유 페이지 빌드, 데스크톱·모바일 Chromium 검사 10개가 모두 통과했다. 나머지 24개 항목의 내용과 전체 순서, 기존 이미지 세 파일의 SHA-256 불변을 확인했다. 이 검증은 웹 동작·데이터 검증이며 범용 이미지 생성 결과의 품질을 검증한 것은 아니다.
