# 아이보리 마네킹 변환 등록

2026-10-18 사용자가 시험 결과의 웹 배포를 요청했다. 실제 시험한 v1 문구와 가상 성인 원본·결과 한 쌍을 mannequin 항목으로 추가했다. 기존 카탈로그 항목의 내용과 상대 순서는 유지하고 새 항목에 기존 최솟값보다 작은 order를 부여했다.

내장 image_gen.imagegen으로 가상 원본 한 장을 생성한 뒤, 그 사진 한 장과 공개 문구만으로 한 번 변환했다. 추가 참고 이미지·사진별 보정 지시·후편집·게시 중 재생성은 없다.

전신 구도, 인물 수, 안경·녹색 카디건·베이지 바지·흰 운동화, 양팔과 다리 위치, 난간과 손의 접촉 및 배경이 유지됐다. 얼굴은 이목구비가 없는 조형으로, 머리카락과 노출 피부는 아이보리색 레진으로 바뀌었고 목·손목에 가는 조립선이 표현됐다. 받침대나 쇼윈도, 다른 인물, 문자·로고는 추가되지 않았다.

손가락 세부와 옷 주름은 미세하게 달라졌다. 얼굴 식별성은 변환 의도에 따라 제거됐다. 성인 인물 한 장만 시험했으며 다른 연령·단체·물건을 든 손·동물·풍경은 검증하지 않았다. 가상 원본·결과임과 이 한계를 공개 설명에 표시했다.

원본·결과는 자르지 않고 무손실 WebP로 변환하고 PNG와 디코딩 픽셀이 같은지 확인했다. 결과·원본은 1024×1536, 썸네일은 560×840이다. [실제 생성 문구·파일·SHA-256 기록](image-generation-2026-10-18-mannequin.json)을 보관한다.
로컬 `npm run check`에서 단위·데이터 검사 14개, 35개 상세 페이지 빌드, 데스크톱·모바일 Chromium 검사 24개가 모두 통과했다. 새 마네킹 항목이 최상단에 표시되고 원본·결과 로딩, 프롬프트 복사, 직접 상세 URL 접속을 확인했다. 기존 34개 항목의 내용과 상대 순서 보존, 공개 문구와 실제 시험 문구 일치, 원본·결과의 PNG↔WebP 디코딩 픽셀 일치 및 비율 유지 썸네일을 별도로 확인했다.
