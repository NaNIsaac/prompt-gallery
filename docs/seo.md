# 기본 SEO

빌드가 카탈로그에서 홈페이지의 실제 상세 링크 목록, 각 상세 페이지의 제목·입력/결과 이미지·사용법·정확한 프롬프트·관련 링크와 sitemap.xml을 자동 생성한다. 새 항목을 정상 등록하면 별도 SEO 파일 편집 없이 다음 빌드에 포함된다. 원문과 기존 예시 설명은 바꾸지 않는다.

정적 본문은 JavaScript 없이도 방문자가 읽을 수 있다. JavaScript로 카탈로그를 성공적으로 불러와 기존 UI를 완성한 뒤 기본적으로 접어 둔다. 방문자는 하단의 목록/사용법 요약을 눌러 언제든 펼칠 수 있다. 로딩에 실패하면 본문을 남긴다. 검색엔진에만 별도 내용을 제공하지 않는다. 실제 색인·순위는 보장하지 않으며 Search Console 등록·사이트맵 제출·검색 유입 확인은 다음 단계다.

사이트맵 주소는 배포 루트 아래 sitemap.xml이다. SITE_URL을 변경하면 canonical과 사이트맵의 절대 URL도 함께 변경된다. GitHub Pages 프로젝트 하위 경로의 robots.txt는 호스트 루트의 robots.txt를 대신하지 않으므로 이 작업에서는 추가하지 않는다.

검증: npm run check. 모든 카탈로그 항목의 정적 본문과 사이트맵 URL, HTML 삽입 방지, JavaScript 비활성 상태의 목록→상세→목록 이동과 이미지/원문 표시, 기존 UI 전환 및 로딩 실패 시 본문 보존을 검사한다.
