## 확인한 범위

기존 원본 6장에 현재 공개 프롬프트를 적용한 재생성 결과를 각각 눈으로 확인했다. 인물 특징, 피사체 구도, 변환 스타일과 명시된 조건을 비교했다. 임의의 다른 사진에 대한 재현성이나 성공률을 보장하는 테스트는 아니다. 원본 PNG는 생성 도구의 기본 저장 위치와 작업용 캐시에 보관하고, 사이트는 로컬 WebP 원본·결과·썸네일을 사용한다.
