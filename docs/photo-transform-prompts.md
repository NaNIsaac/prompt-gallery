# 사진 변환 프롬프트와 생성 예시

2026-10-15. 내장 이미지 생성 도구로 서로 다른 첨부 예시 6장을 먼저 만들었다. 각 예시만 입력 이미지로 첨부하고, 아래에 적힌 짧은 변환 프롬프트를 그대로 보내 결과를 생성했다. 도구에 별도의 스타일·품질 지시를 덧붙이지 않았다. 예시 인물과 장소 장면은 생성 이미지이며 실제 사용자의 사진이 아니다.

기존 디오라마 항목과 그 프롬프트·이미지는 그대로 유지했다. 공개 갤러리는 디오라마와 아래 6개, 총 7개로 구성한다. 기존 커뮤니티 결과 이미지는 제거했으며 아래 링크는 각 스타일의 참고 출처다. 사진에 맞추는 핵심 지시만 남기고 대상의 성별·외모·장소·브랜드·활동을 고정하지 않았다.

## 확인한 범위

각 예시 한 쌍에서 인물/사물 특징과 변환 효과를 눈으로 확인했다. 임의의 다른 사진에 대한 재현성이나 성공률을 보장하는 테스트는 아니다. 원본 PNG는 생성 도구의 기본 저장 위치와 작업용 캐시에 보관하고, 사이트는 로컬 WebP 원본·결과·썸네일을 사용한다.
