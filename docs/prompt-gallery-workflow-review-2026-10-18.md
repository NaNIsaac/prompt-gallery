# 프롬프트 작업 스킬 검토

2026-10-18 사용자가 요청한 프롬프트 제작·테스트·등록 흐름에 별도 브랜치 시작과 배포 후 브랜치·작업 공간 정리를 포함하여 `.agents/skills/prompt-gallery-workflow/`에 저장소 전용 스킬을 추가했다.

- 작업 브랜치: `codex/prompt-gallery-workflow`. 기준 커밋: `f672774c2f0d50099ddab774f227cc991476efe9`. 원래 작업 폴더의 종이 팝업북 변경은 별도로 보존했다.
- `SKILL.md`는 요청 범위·작업 시작·제작·게시의 공통 판단을, 세 참조 파일은 품질·게시 수명주기·검증 시나리오를 다룬다. 기존 imagegen과 저장소의 검사·배포 문서를 재사용하며 프롬프트·이미지·사이트 기능은 바꾸지 않는다.
- 공식 `quick_validate.py` 통과. 독립 검토의 적용 판단 5건과 제외 판단 3건은 모두 기대 범위에 맞았다. 중단 재개·dirty 작업 보존·변경 없는 재시험·예시 연결·현재 커밋 CI·공개 404·정리 전 ref 전진의 7개 시나리오도 검토했다. 이는 문서를 읽고 수행한 독립 판단이며 실제 자동 호출 실행 결과는 아니다. 이 환경에는 `skill.check_trigger`가 없어 자동 선택은 검증하지 못했다.
- 독립 검토에서 나온 두 지적을 반영했다. 같은 문구로 시험만 요청했을 때 수정하지 않도록 했으며, 원격 브랜치 삭제는 병합된 head SHA를 조건으로 하여 정리 직전의 새 커밋을 보존한다. 수정 부분을 재검토하여 해소를 확인했다.
- `npm run check` 통과: 단위·데이터 검사 14개, 정적 빌드, 데스크톱·모바일 Chromium 검사 24개. 스킬과 관련 문서 링크를 확인했다.

실제 사용에서 자동 호출 누락이나 오호출이 발견되면 description과 위 검증 사례를 함께 보완한다. 스킬 변경만으로 새 이미지 생성이나 외부 배포 요청에 대한 포괄적인 권한이 생기지는 않는다.

## 기여자 공유 흐름 보완

2026-10-18 후속 요청으로 일반 기여자의 fork·PR 제출과 담당자의 검토·병합·배포를 구분했다. 스킬은 저장소 파일로 공유하고 기여 안내에 호출 예시와 원본 base·본인 head·origin/upstream 구분을 추가했다. push 권한만으로 담당자를 가정하지 않으며, 검토만 요청한 경우 병합하지 않는다. 외부 workflow 승인 대기와 실제 실패를 구분하고, 담당자가 기여자의 fork 브랜치를 삭제하지 않도록 했다.

공식 스킬 형식 검사와 문서 링크 검사, npm run check(단위·데이터 14개 및 데스크톱·모바일 24개)를 통과했다. 독립 검토에서 fork routing·기여자 인계·workflow 승인 대기·담당자 역할/권한/요청 범위·외부 PR·정리 소유권을 확인했고, 기존 개발 문서의 origin/main 가정과 검토 요청만으로 병합할 수 있는 표현을 수정한 뒤 재검토했다. 이는 문서 기반 검토이며 외부 기여자의 실제 계정으로 fork·PR을 만들거나 자동 호출을 실행한 검증은 아니다.
