# 카트라이더 인게임 레이서 2차 결과 등록 검토

2026-10-17. 사용자가 승인한 2차 결과와 해당 생성에 사용한 전체 프롬프트를 `kartrider-ingame-character`로 등록했다. 신규 항목을 기존 최솟값보다 작은 `order: -20`으로 최상단에 추가했다. 등록 시 기존 25개 항목의 내용과 상대 순서를 유지해 총 26개가 됐다.

[원본](../assets/images/kartrider-ingame-character.reference.webp) · [결과](../assets/images/kartrider-ingame-character.webp) · [실제 입력·두 차례 테스트·파일 해시](image-generation-2026-10-17-kartrider.json)

내장 이미지 생성 도구로 가상의 성인 여성 전신 사진을 만들고, 같은 원본 한 장에 두 버전의 프롬프트를 각각 적용했다. 1차는 눈과 카트의 디테일, 광택과 배경 흐림이 캐릭터 일러스트에 가까웠다. 2차는 1차 문구에 단순한 눈·머리카락·게임 모델과 균일한 게임 조명을 요구하는 화풍 보정을 추가했다. 2차에는 1차 결과를 첨부하지 않았다. 공개 문구는 기록된 2차 입력 전체와 일치한다.

단발머리·붉은 안경·주황색과 크림색 재킷·남색 바지, 얼굴이 보이는 헬멧, 운전대를 잡은 손, 카트 전체, 빌리지풍 트랙과 순위·랩·속도·부스터 HUD를 확인했다. 1차보다 눈과 머리카락, 카트와 배경의 표현이 단순해졌다. 실제 사용자 사진이나 실제 게임 캡처는 아니다. 얼굴의 단순화로 닮은 정도에는 한계가 있고, 배경과 카트는 각진 부분이 있으며 미니맵·HUD 디자인도 원작을 정확히 재현하지 않는다. 이러한 차이를 공개 예시 설명에 표시했다. 다른 인물과 단체 사진은 생성 테스트하지 않았다.

원본은 941×1672, 결과는 1448×1086, 썸네일은 560×420이다. 원본과 결과를 자르거나 보정하지 않고 무손실 WebP로 변환했으며, 변환 전후 디코딩된 픽셀 일치를 확인했다. 썸네일만 결과의 비율을 유지해 축소했다. 생성 기록에 실제 도구 입력과 원본 PNG·공개 자산의 크기 및 SHA-256을 보관한다.

최신 main을 반영한 통합 상태에서 `npm run check`의 단위·데이터 검사 14개, 상세 페이지 26개 빌드, 데스크톱·모바일 Chromium 검사 10개가 통과했다. 공개 프롬프트와 실제 2차 도구 입력의 일치, 최신 main의 기존 25개 항목 보존과 신규 최상단 배치를 확인했다.
