# 숲 이중노출 얼굴의 그림체 수정

2026-10-17. 사용자의 “얼굴 더 그림처럼 보이게 해줘” 요청을 반영해 `forest-double-exposure`의 공개 문구와 결과·썸네일을 수정했다.

## 변경과 입력

얼굴도 처음부터 손으로 그리도록 지시하고, 피부의 부드러운 색면·수채화 번짐·종이 결과 코·입술·눈의 색연필 선을 명시했다. 사진 같은 피부·눈·입술 광택과 세밀한 모공 표현은 줄이도록 했다. 머리카락과 숲·산도 같은 수채화·색연필 매체로 연결한다.

기존의 AI 생성 정면 인물 원본을 그대로 사용했다. 현재 공개된 원본 WebP 한 장과 수정한 공개 프롬프트만 내장 `image_gen` 도구에 전달했다. 이전 변환 결과나 외부 스타일 이미지를 첨부하지 않았고 후속 지시나 재시도는 없었다. 정면 사진 입력 안내와 옆모습 재해석 방식, 항목 ID와 등록 순서는 유지했다.

[정면 원본](../assets/images/forest-double-exposure.reference.webp) · [수정 결과](../assets/images/forest-double-exposure.webp)

## 결과 검토

이전 결과보다 피부가 수채화 색면과 종이 결로 표현되고, 코·입·귀와 머리카락 주변에 그린 선이 드러난다. 얼굴과 숲·산의 수채화 표현이 이어지며 차가운 파랑·이끼색과 따뜻한 새벽빛, 밝은 여백을 유지했다. 글자·로고·워터마크는 보이지 않는다.

눈과 머리카락에는 여전히 세부 표현이 남아 있어 완전한 단색 실루엣으로 설명하지 않는다. 같은 정면 사진을 새로 변환했으므로 머리 방향과 얼굴·숲의 구도는 이전 결과와 완전히 같지 않다. 보이지 않던 옆얼굴은 생성 모델의 재해석이며 얼굴의 정확한 복원이 아니다. 이 내용을 현재 `exampleNote`에 표시했다.

원본과 결과는 1024×1536이고 썸네일은 560×840이다. 결과 전체를 자르거나 별도 보정하지 않고 WebP로 변환했으며 썸네일만 비율에 맞게 축소했다. 다른 사진에서의 재현성은 검증하지 않았다.

## 이력

[수정 프롬프트·실제 입력·파일 해시](image-generation-2026-10-17-forest-illustration.json)에 현재 결과를 기록했다. 이전 결과·프롬프트의 파일 해시와 Git 기준 커밋을 함께 보관한다. [최초 등록 기록](image-generation-2026-10-17-aesthetic.json)은 당시 사실을 유지하며, 그 결과·썸네일 경로와 해시는 최초 등록 커밋의 파일에 해당한다.

## 검증

`npm run check`를 실행해 단위·데이터 검사 14개, 22개 공유 페이지 빌드와 데스크톱·모바일 브라우저 검사 10개를 모두 통과했다. 다른 21개 카탈로그 항목과 원본 이미지·항목 ID·등록 순서를 유지했으며, 공개 프롬프트와 실제 도구 입력, 원본·결과·썸네일의 파일 해시를 확인했다.
