# UX 복구 및 검증 기록 — 2026-10-15

## 목표와 유지 범위

GitHub Pages에서 동작하는 정적 이미지 프롬프트 갤러리다. 사용자의 주요 흐름은 결과 이미지 탐색 → 마음에 드는 프롬프트 즉시 복사다. 검색, 카테고리, 사진 필요 여부 필터, 정렬, 브라우저 저장, 상세 이미지·사용법·레퍼런스·출처, 공유 링크, 이전/다음, 소개를 유지한다. 제작 과정과 버전 관리는 Git에 두고 화면에 추가하지 않는다.

새 서비스 패턴이나 장식용 패널을 추가하지 않고 익숙한 컨트롤, 명확한 문구, 일관된 크기와 상태 피드백을 우선한다. 데이터 스키마, 검색·정렬 알고리즘, 저장 키, 빌드 및 Pages 워크플로는 유지했다.

## 중단 당시 실제 상태

- 기준 커밋은 `31a6dd3`이다. 기존 갤러리 구현은 커밋되어 있었다.
- UX 변경은 `index.html`, `styles.css`에 부분 반영됐지만 `app.js`는 이전 마크업을 참조했다.
- 실제 브라우저에서 삭제된 `#mobile-detail-copy`에 이벤트를 연결하면서 `TypeError: Cannot read properties of null (reading 'addEventListener')`가 발생했다. 카탈로그 로딩 전 시작이 중단됐다.
- 기존 Node 테스트 5개와 구문 검사는 통과했다. 따라서 이 검사만으로 화면 완료를 판단할 수 없었다.
- README, 카탈로그, 디오라마 이미지 3개는 복구 시작 때 이미 변경/추가된 상태였다. 기존 대화만으로 작성 경위를 확정할 수 없어 보존했다. 이번 UX 작업에서 README와 카탈로그의 SHA-256이 시작 시점과 동일함을 확인했다. 전체 17개 항목으로 검증했다.

## 실행한 검증

- `node --check app.js`, `node --check scripts/serve.mjs`: 통과.
- `npm test`: 10개 통과. 기존 5개에 화면별 상태/초기화/모달 범위/복사 실패 처리 4개, HTML-JS ID 연결 1개를 추가했다.
- `npm run build`: 카탈로그와 로컬 자산 검증 후 17개 항목 빌드 성공.
- `git diff --check`: 오류 없음.
- 브라우저에서 17개 항목 로딩과 활성 컨트롤, 검색, 카테고리/사진 필터 교집합과 빈 결과, 정렬, 목록 카드/상세 복사를 확인했다. 상세 복사는 클립보드 내용과 검색 입력에 붙여넣은 원문으로 확인했다.
- 저장/취소/실행 취소, 새로고침 후 저장 유지, 화면별 검색 보존, 저장 화면에서 초기화, 상세에서 저장 취소 후 동일한 2개 목록 내 이동, 닫기 후 남은 카드로 포커스 복원을 확인했다. 검증에 추가한 북마크는 제거했다.
- 직접 해시 링크로 진입/새로고침, 링크 복사, 이전/다음, 브라우저 뒤로/앞으로, Escape, 소개를 확인했다.
- 320×568, 390×844, 768×1024, 1024×768과 기본 데스크톱 화면을 점검했다. 가로 넘침과 모바일 카드 겹침이 없고 주요 버튼/정렬/체크박스 라벨은 44px 이상이다. 상세 본문을 스크롤해도 닫기·복사가 화면에 남고, 원문 전체 보기/접기가 동작했다.
- 임시 로컬 QA 프록시에서 JSON 응답을 503으로 바꿔 오류 안내를 확인하고 정상 응답 복구 후 재시도로 17개가 다시 표시됨을 확인했다. 썸네일/상세 이미지 실패 안내와 상세 이미지 재시도 후 실제 이미지 복구도 확인했다. 테스트용 실패 설정은 제품 코드에 넣지 않았다.
- 상세 이미지 응답을 1.5초 지연시켜 로딩 중 이전 이미지가 숨겨지고 준비 후 해당 이미지가 나타나는 것을 확인했다. 이미지 로딩 전후와 상세 이동 중에도 헤더/액션 푸터의 위치가 유지되도록 모달 높이를 고정했다. 재시도 성공 시 카탈로그는 검색 입력, 이미지는 원본 링크로 포커스가 이어짐도 확인했다.
- 복사 API 거부와 모든 복사 경로 실패는 단위 테스트로 확인했다. 실제 브라우저 권한 거부·저장소 차단, 스크린리더, 실물 iOS/Android, Safari/Firefox는 검증하지 않았다.
- gradient, 그림자, 새 애니메이션, 버전 관리 UI, 장식용 패널을 추가하지 않았음을 소스에서 확인했다.
